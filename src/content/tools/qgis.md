## Overview

QGIS is a mature, free, and open-source Geographic Information System used across climate-adaptation work — from mapping heat-vulnerability indices to overlaying flood extents on demographic data. It reads virtually every common spatial format and offers hundreds of analysis tools plus a Python API for automation.

## Key features

- Cross-platform desktop application (Windows, macOS, Linux)
- Extensive plugin ecosystem and the "Processing" analysis toolbox
- Native support for PostGIS, web tile services, and remote-sensing data

## Who it's for

Planners, analysts, and researchers who need a no-cost, professional-grade GIS for climate and land-use analysis.

## Getting started

Download QGIS from [qgis.org](https://qgis.org) and follow the built-in training material, or install community plugins for specialised climate workflows.
