## Overview

OSMnx is an open-source Python package by Geoff Boeing for downloading, modelling, analysing and visualising street networks and other geospatial features from OpenStreetMap. It is released under the MIT licence; OpenStreetMap's own data licence requires attribution.

## Key features

- Download and model walking, driving or cycling networks
- Work with points of interest, building footprints, transit stops and elevation data
- Analyse street orientation, speeds and travel times, and compute routes

## Who it's for

Analysts and researchers who code in Python, for example to study walkability, evacuation routes or access to cooling centres.

## Getting started

See the [documentation](https://osmnx.readthedocs.io/) for installation and examples, or the [GitHub repository](https://github.com/gboeing/osmnx).
