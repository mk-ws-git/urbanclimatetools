# Content calendar

_Plan: 2 case studies and 2 tools per month, published on Tuesdays. Machine-readable copy: `content/calendar.json` (the automation reads that file)._

**Rhythm:** 1st and 3rd Tuesday = case study; 2nd and 4th Tuesday = tool. One post per Tuesday keeps social posting steady and gives each item its own moment.

**Every entry must pass** the verification checklist in `docs/CONTENT-PLAN.md` (official source, sourced facts, licence, links, CC-only photo with credit, clean build). Names below are candidates; the drafting step confirms each exists and is well documented, and swaps in a reserve if not.

**Reserve list:** Norfolk, Minneapolis, Hamburg, Dar es Salaam, Buenos Aires, Jakarta follow-up, Rotterdam follow-up (cases); Tree-planting toolkits, urban heat sensor networks (tools).
